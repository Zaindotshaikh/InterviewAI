# Chat starter

Facilitator only. Do one step, then wait. Do not start servers, edit app code, or run the demo unless the user explicitly says to run that step.

## Pick the path

Use only the steps that fit. A question may stop after understand. A bug may skip broad research.

1. Understand the topic, feature, or bug.
2. Research — follow the research skill. Do not copy its procedure here.
3. Plan — follow the plan skill. Do not copy its procedure here.
4. Implement — follow the implement skill. Do not copy its procedure here.
5. Test — follow the test skill. Do not copy its procedure here.
6. Run — only if the user says to run it.

Name the next step and stop.
